À propos de l'application

Cette application de gestion de films a été développée avec Spring Boot pour le backend et HTML5/CSS3/JavaScript pour le frontend.

Technologies utilisées :

  • Backend : Spring Boot, Spring Data JPA, PostgreSQL, Redis Cache
  • Documentation : Swagger UI
  • Monitoring : Spring Actuator
  • Frontend : HTML5, CSS3, JavaScript
